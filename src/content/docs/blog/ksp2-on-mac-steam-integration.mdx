Hey! I'm Ewy from the Redux team. I mostly work on the infrastructure and boring stuff, like the launcher, the command line tool, the release pipeline and this website you're reading right now. I don't make any of the flashy cool stuff you see in the game, that's all the other people on the team. But every once in a while the boring stuff gets to be a bit exciting too, and this is one of those times.

Launcher 0.6.0 is out, and it's a big one. The short version: KSP2 now runs on a Mac, you can sign in to Steam and download the game straight from the launcher, and the command line tool can finally do everything the launcher can.

## KSP2 on a Mac

KSP2 never came out for the Mac. There is no macOS build of the game, and Steam won't even let you download it on one. Getting it running on a Mac before meant setting up something like CrossOver yourself and fiddling with it until it maybe worked.

I've been working on this for quite a while now, and the goal was always the same: make KSP2 with Redux just work on a Mac, without any of that. That meant building our own Wine runtime and shipping it inside the launcher, getting CI to build all of it automatically, teaching the launcher to download the game from Steam by itself, and chasing down a whole pile of small Mac-only problems along the way, like Rosetta missing or macOS refusing to open an unsigned app. It took a lot longer than I'd like to admit, but it works now, and I'm honestly pretty proud of how it turned out.

So the macOS launcher brings its own Wine runtime and runs the Windows version of the game.

![The KSP2 Redux launcher open on a macOS desktop, with the Snapshot 26w39b build selected and the Launch button ready](../../../assets/blog/launcher-0-6-0/mac-desktop-launcher.png)

A bit more detail for the curious: Wine runs the Windows game, and DXMT translates the game's Direct3D 11 calls to Metal, which is what the GPU in your Mac actually speaks. The runtime is built from CodeWeavers' open source release of CrossOver 26.3 and bundled inside the app, so there's nothing to install or set up. If you already have CrossOver installed the launcher can use that too.

It's Apple Silicon only for now, and it needs Rosetta 2 since the game and Wine are x86_64. If Rosetta is missing the launcher tells you how to install it instead of just falling over.

![KSP2 Redux running in a window on macOS, with a rocket on the launch pad at the KSC and the macOS menu bar and Dock visible](../../../assets/blog/launcher-0-6-0/mac-game.png)

Yes, that's KSP2 Redux sitting on the launch pad in a window on a Mac. It still feels a bit weird every time I see it.

Once everything is set up it's one click to play, you just press Launch like on any other platform. The first time takes a few more steps though:

1. Open the `.dmg` and drag KSP2 Redux into Applications
2. Approve the app the first time you open it. It isn't signed by Apple yet so macOS will complain about it, the launcher walks you through it (Privacy & Security, then Open Anyway)
3. Sign in to Steam
4. Download KSP2
5. Install Redux and hit Launch

## Signing in to Steam

This is the part that makes the Mac version possible in the first place. Since Steam won't download KSP2 on a Mac, the launcher now talks to Steam itself (using SteamKit2) and downloads the Windows version of the game from your own account. This works on Windows and Linux too, so you don't need the Steam client at all if you don't want it.

You can sign in by scanning a QR code with the Steam Mobile App, or with your password and Steam Guard.

![The Sign in with Steam dialog in the launcher, with a QR code for the Steam Mobile App on the left and account name and password fields on the right](../../../assets/blog/launcher-0-6-0/steam-sign-in.png)

Downloads can be stopped and picked up again later, and it can only download a copy you actually own. So no, this is not a way to get the game for free. There's also a little Steam indicator in the bottom right corner that shows if you're connected, and clicking it lets you sign in, download or sign out.

![The launcher downloading Kerbal Space Program 2 from Steam, at 29.5 of 31.0 GB with 4284 of 4287 files done](../../../assets/blog/launcher-0-6-0/steam-download.png)

The whole game is about 31 GB, so it's nice that you don't have to start over if your Wi-Fi drops halfway through.

A quick note on security, since you're giving the launcher your Steam login. Your password is never saved. What gets saved is the sign-in token, and that's kept in Windows data protection on Windows, the keychain on macOS, and a file only your user can read on Linux. Signing out also revokes it on Steam's side, not just on your computer, and your Steam login name isn't written to the launcher log anymore.

## The CLI caught up

The command line tool, `redux-launcher-cli`, has been a bit behind the launcher for a while. Not anymore. It has a macOS build now, and it launches and stops the game through the same Wine runtime and prefix as the launcher, so your saves are shared between the two.

New stuff:

- `steam login`, `logout`, `status` and `download`, and the QR code gets drawn right in your terminal
- `installs show`, `set` and `delete` for the install settings, like the game path, launch arguments, gfx jobs and launch via Steam
- `settings` for the launcher-wide stuff, like the patch source and concurrent chunks
- `open` for the install, logs, game data and storage folders
- `news` for the latest posts from this blog (hi)

`doctor` got some love too. It lines up its values now and reports the Wine runtime, Rosetta and whether you're signed in to Steam, which makes it a lot easier to help people when something goes wrong.

This is what you get if you just run it with no arguments. Yes, it has a pixel art logo.

![The redux-launcher-cli help screen in a macOS terminal, with a pixel art KSP2 Redux logo and the full list of commands](../../../assets/blog/launcher-0-6-0/cli-help.png)

So you can now go from nothing to playing KSP2 Redux without opening a single window. Not sure who needs that, but it's there. Okay, I need that.

## Everything else

The Settings tab got reworked around install profiles, so you can keep several KSP2 installs side by side, like a clean one and one for mods, and switch between them. The pencil next to the dropdown renames them.

![The launcher's Settings tab with the install profile dropdown open, showing a KSP2 with Mods profile and a KSP2 Steam download profile](../../../assets/blog/launcher-0-6-0/settings-profiles.png)

There's also a Browse button for the game executable, a Download KSP2 button right there in the profile, and an Uninstall KSP2 button that deletes the game but keeps your saves. If Steam manages that copy it just hands it back to Steam instead. The spacing is also finally even, which was bothering me way more than it should have.

![The reworked Settings tab, with the install profile, game executable with a Browse button, Uninstall Redux and Uninstall KSP2 buttons, and the advanced download settings](../../../assets/blog/launcher-0-6-0/settings.png)

And a bunch of fixes. The launcher could get stuck on startup because a prompt opened behind the main window, and it could close without a word if it crashed while starting. Now it shows the error and writes it to `bootstrap.log` in the logs folder. If the launcher crashes or doesn't show up at all (mostly on Windows 10), try adding `--software-rendering` or `--no-composition` to the end of the shortcut's Target.

The full changelog is on [GitHub](https://github.com/KSP2Redux/Updater/releases/tag/updater-v0.6.0.0).

## Download

Get it from the [download page](/download/). On a Mac that's `KSP2-Redux-macOS-arm64.dmg`. If you already have the launcher, it should offer to update itself.

This is the first version of the Mac launcher so things will break. If something does, run `redux-launcher-cli doctor`, and send the output along with your report on the [Discord](https://discord.gg/ksp2redux) or on [GitHub](https://github.com/KSP2Redux/Updater/issues).

Have fun!
