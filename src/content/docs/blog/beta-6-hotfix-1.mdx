Shortly after Beta 6 went out, we released a quick hotfix for the 6th beta of KSP2 Redux that fixes the Chinese localization, once again.

**To install, use the** [**Redux Updater app**](https://github.com/KSP2Redux/Updater/releases/latest)**, do not download any files from the release page manually.** Beta 6 Hotfix 1 has since been replaced by newer releases, so the Updater will install the latest version.

You can find the release on the [Redux GitHub page](https://github.com/KSP2Redux/Redux/releases/tag/v0.2.8.1.102312).

## Bug Fixes

* Fixed: Chinese localization
