# Redux Snapshot 26w42a

This snapshot is the culmination of our work porting KSP2 Redux from Unity's Builtin Render Pipeline to the Universal Render Pipeline, allowing us to leverage it for stuff like Reflections, Planetary Shadows, DLSS, and more. Alongside that this contains a major change to how modding works, allowing players to declare what mod "features" are enabled on a per-campaign basis.

The URP work is still WIP, there will likely be visual bugs - if you find them please make sure to report them using the menu (Report Redux Bug) or the hotkey (Ctrl-B)
