## What is KSP2 Redux?

KSP2 Redux is a fan project built on top of Kerbal Space Program 2. The current
work is mostly focused on:

- **Performance work:** Rendering, simulation, and memory improvements
- **Bug fixing:** Flight issues, UI problems, mission logic, map view behavior,
  and other stock problems
- **Roadmap systems:** Heat, vessel ISRU, colony-related groundwork, and later
  planned features
- **Modding support:** A better workflow for Redux-native mod development

Redux is a volunteer project. Work moves when people have the time and energy to
work on it. For that reason, we do not have any estimates or deadlines for when
features will be completed. Please be patient and understand that this is a
hobby project, not a commercial product.

If you want to join the project, see the [Contributing](/guides/contributing/)
page for information on how to help.

## Current status

Redux is currently in **Stage 0: Foundation**. That means that most of our work
is still centered on making the base game more efficient, less fragile, and
easier to build upon.

For the current feature summary, see [Implemented Features and
Fixes](/guides/implemented-features-and-fixes/). For longer-term project
direction and stage progress, see the [Roadmap](/roadmap/).

## Important Notes

- **Beta Software:** Redux is currently in beta. Some features may be incomplete
  or buggy.
- **No Official Affiliation:** Redux has no connection to the former KSP2
  developers, Private Division, Fictions, or KerbalCo.
- **Volunteer Project:** Redux is developed entirely by volunteers in their free
  time.
