Reduxは現在、まだベータ版です。Redux導入前のKSP2（バニラ版）と比較すると、新たなパーツやミッションの追加、飛行およびマップビューの改善、EVAの拡充、UIの整理、グラフィックのアップデート、インストーラーの整備、Mod制作ツールの導入に加え、ゲーム全体にわたる多数の修正が含まれています。

このページでは、Reduxにすでに導入されている主な要素を、分野ごとに分類してリストしています。完全なリリースノートよりも読みやすい構成になっています。

各アップデートの完全なリリースノートについては、[開発者ブログ](/blog/)および[GitHubリリース](https://github.com/KSP2Redux/Redux/releases)をご覧ください。

これは、**v0.2.8.5**時点での公開状態を反映しています。

## 概要

- ゲームエンジンはUnity
  6.4にアップグレードされました。また、MOD制作ツールも強化されており、「Redux」MOD制作SDKやMODテンプレートに加え、KSP2向けの「SpaceWarp」、「Patch
  Manager」、「UITK」が統合されています。
- Reduxでは、新たなパーツ、技術ツリーの変更、新規ミッション、EVA用パラシュート、ヘルメットライト、カスタム旗、ステッカー、そして統計ウィンドウが追加されます。
- フライトビューおよびマップビューには、実用的な修正や追加要素が数多くあります。具体的には、SASの改善、より高速なタイムワープ、KSP1スタイルの軌道カメラの挙動、一時停止中のマニューバノード編集、マップ上のフラグ表示、機体カテゴリ分けなどが含まれます。
- VABおよび組み立て工程において、取り消し、ストラット、対称配置、ステージング、フェアリング、ドッキングポート、パーツアクション、そしてパーツ配置時のパフォーマンスといった各要素を中心に、多くの修正が行われました。
- UI関連の作業には、新しい「カラーマネージャー」、作り直された「軌道情報パネル」、パーツ選択時の検索機能の改善、より分かりやすくなった通知、ローカライズおよびフォント処理の最適化など、さまざまなUIの改善が含まれています。
- グラフィック、エフェクト、パフォーマンス面では、雲やレンズフレアの変更、惑星ごとに異なる大気圏再突入時の色、スーパーサンプリング、マルチスレッド・レンダリング設定の導入のほか、シミュレーションやUIの各システムにおけるメモリ割り当て負荷の低減などが行われています。

## 追加・改善された機能

### パーツと技術ツリー

- TCS-400XやTCS-200Fラジエーターをはじめとする、新たな熱制御パーツを追加。
- SM+のエンジン、燃料タンク、アダプター、デカップラー、セパレーター、ブースター、耐熱シールド、円錐形のクルーポッド、およびプローブコアを追加。
- 微小型の固体ロケットブースター、カメラパーツ、プロシージャルなボディフラップ、そしてステッカーデカールパーツを追加。
- Reduxのパーツを含めるために技術ツリーを拡張。
- フェアリングに、オプションのインターステージサポートを追加。
- MOD制作者がパーツアイコン、ドラッグキューブ、再突入メッシュ、エンジンプルーム、フェアリングシュラウドを生成するのに役立つSDKツールを追加。
- パーツシェーダー、オーディオ設定、インタラクションプリセット、ハシゴ、エアロックに関するSDKヘルパーを追加。

### フライトおよびマップビュー

- 立てられた旗は、マップビュー上でそれぞれの旗の色で表示されるようになりました。
- マップビューから旗を削除することができ、キャンペーンの旗が変更された場合でも、すでに立てた旗は元のデザインのまま維持されます。
- 飛行中にカメラの視野角を調整できる機能を追加。
- ダブルクリックによるパーツフォーカス機能と、フライトカメラの状態をリセットするキーバインドを追加。
- KSP1スタイルの天体・軌道カメラの挙動を追加。
- 一時停止中にマニューバノードを作成・編集できる機能を追加。
- マニューバノードギズモに対して、マウスホイールによる精密な入力操作を追加。
- Improved maneuver node popups and burn patch colors in map view.
- Added notifications when precision input mode changes or trim is
  applied/reset.
- Added clearer feedback for time warp limits and warping to a point.
- Added physics warp initiation in space with the Alt key.
- Added 10,000,000x time warp.
- Improved time warp limits so safe orbits are less constrained.
- Improved physics warp status text and color feedback.
- Added vessel categories and icons for clearer map and tracking station
  identity.
- Added aerodynamic stress behavior for deployed parts.
- Improved SAS stability, including several edge-case bug fixes and improved
  high dynamic pressure behavior.
- Added flight input smoothing for normal and precision mode.
- Improved vessel naming after decoupling, undocking, and docking.

### EVA

- Added toggleable Kerbal helmet lights.
- Added helmet toggling on oxygen worlds and inside command pods.
- Added EVA parachutes, including gliding, agency colors, and external seat
  support.
- Allowed EVA Kerbals to take stored science reports out of command pods and
  probes.
- Disabled the EVA exit obstruction check to reduce blocked exits in common
  cases.

- Added stored research reports to the flight report window.
- Added a lower minimum science rewards difficulty option.

  panels, RCS, wheels, engines, resources, drag, the message center, sessions,
  and data contexts.
- Cached expensive ownership and getter lookups in frequently used code.
- Removed unused IMGUI event processing.
- Reduced save UI hierarchy and layout overhead.
- Improved orphaned part scanning.
- Improved DeltaV stage timing calculations.
- Fixed memory leaks and unnecessary rebuilds in thermal code.
- Reduced overhead for vessels orbiting Kerbol.
