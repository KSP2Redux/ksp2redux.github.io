## 3Dアーティスト

開発は、多数の3Dモデル、テクスチャ、天体、その他ビジュアルコンテンツの制作に着手すべき段階に差し掛かっています。

### 必要なもの

- **パーツモデル：** 新たな機体パーツ、コロニーパーツ、軌道構造物、恒星間航行エンジン
- **テクスチャ：** パーツおよび環境向けの高品質なPBRテクスチャ
- **天体：** デブデブ（Debdeb）星系の惑星および衛星
- ***アセットパイプライン：** 今後のReduxコンテンツに向けた、アートガイドラインおよびアセットワークフローの策定を支援

### 求めるスキル

- 3Dモデリング (Blender、Maya、3ds Max)
- テクスチャリングおよびマテリアル（Substance Painter、Photoshop）
- Unityの経験（あれば望ましいですが、必須ではありません）
- ゲームアセットの最適化に関する理解
- リアルタイムゲーム向けのアセット制作経験

### はじめるには

<Aside type="tip">
こうした分野での経験をお持ちのアーティストの方、ぜひこのプロジェクトにご協力いただければ幸いです！
</Aside>

**アートリードをコンタクト：**
- [KSP2 Redux Discord](https://discord.gg/ksp2redux) に参加
- **#🟡redux-chat** チャンネルへ移動
- 制作実績を添えて、**@safarte** までDMを送ってください。

## デザイン、アニメーション、動画

Reduxでは、3Dゲームアセット以外のビジュアル素材に関してもサポートを必要としています。

### 必要なもの

- **2Dアートおよびアニメーション：** ゲーム内チュートリアル動画、ミッション用アニメーション、コンセプトアート、およびプロモーション用素材（想定）
- **グラフィックおよびWebデザイン：**
  ウェブサイトの改善、開発アップデート用グラフィック、SNS投稿用画像、インフォグラフィック、その他コミュニティ向けビジュアルの制作
- **動画編集：** 機能紹介動画、ショーケース動画、短いアップデート用クリップ
- **執筆および編集:** 分かりやすいドキュメント、開発アップデート、その他一般向け資料

### はじめるには

Discordで、**@.munix** または **@safarte**
までに、これまでの制作物の例をお送りください。スクリーンショット、レンダリング画像、アニメーションリール、デザイン作品、動画、執筆サンプル、あるいはポートフォリオへのリンクなどが適しています。

<a id="contribute-developers"></a>

## 開発者

ロードマップ上の目標を達成するため、チームに参加してくださるアクティブなボランティア開発者を募集しています！

### 求めるスキル

理想としては、以下のいずれか（または複数）の分野で経験をお持ちの方を求めています：

- **KSP1/KSP2のMOD開発：** ゲームのシステムおよびMOD制作に関する知識や経験
- **グラフィックスプログラミングおよびテクニカルアート：** HLSL、Unity Shader
  Graph、ShaderLab、URP、レンダリング、ライティング、ポストプロセッシング
- **Unity開発：** C#スクリプト、ECS/DOTS、ゲームシステム
- **C#プログラミング：** C#の強固な基礎とベストプラクティス

### 取り組む内容

あなたのスキルや関心に応じて：
- パフォーマンス最適化（ECS、DOTS、プロファイリング）
- 主要なゲームシステム（コロニー、資源、マルチプレイヤー）
- グラフィックスの改善（Built-in Render
  PipelineからURPへの移行、シェーダー、再突入時のVFX、エンジンプルーム、レンダリング、ライティング、ポストプロセッシングなど）
- MOD開発SDKおよびツール
- バグ修正および品質改善

### 応募する方法

<Aside type="note">
開発チームへの参加にあたっては、プロジェクトに有意義に貢献できることを確認するため、経験を証明するものの提示を求めています。
</Aside>

**DiscordのDMで、以下の内容を @.munix または @safarte までお送りください：**
- あなたのGitHubページ
- あなたが作成したMODへのリンク
- あなたが携わったゲームに関する情報
- その他に関連する経験
- KSP2を所有していることの証明

これにより、私たちはあなたのスキルを把握し、あなたが貢献できる最適な領域を見つけることができます。

## 翻訳者

英語に抵抗がなく、かつ以下に挙げた言語のいずれかに流暢で、『KSP2 Redux』への貢献に関心があるという方――まさに絶好のチャンスです！

### 必要な言語

特に、以下の言語の翻訳者を募集しています：

- 中国語（繁体字）
- イタリア語
- 日本語
- 韓国語
- ポルトガル語（ブラジル）
- スペイン語

フランス語、ドイツ語、ポーランド語、ロシア語、中国語（簡体字）など、他の言語も依然として役立つ可能性があります。

### 翻訳する内容

- UIテキストおよびメニュー
- パーツデスクリプションおよびテクニカル情報
- チュートリアルコンテンツおよびツールチップ
- ミッションデスクリプション
- ゲーム内のメッセージおよび通知

### はじめるには

**翻訳コーディネーターまでコンタクトしてください：**
- [KSP2 Redux Discord](https://discord.gg/ksp2redux) に参加
- 翻訳可能な言語を明記の上、**@safarte** までDMをお送りください。

## MOD開発者

### 既存のMODを更新

KSP2のMODを管理されている方へ、それらのMODをReduxへ移行するお手伝いをさせてください！

**変更点：**
- BepInExから統合型MODローダーへの移行
- 新しいエンドポイントを追加し、MOD開発APIを改善
- コアシステムの書き換え（例：TransformFrame）
- 開発に向けたUnityエディター統合

**移行に関するサポートを受ける：**
- [KSP2 Redux Discord](https://discord.gg/ksp2redux) の **#🔴mod-dev** に参加
- [MOD開発ドキュメント](https://modding.ksp2redux.org) を読む
- [Redux APIドキュメント](https://api.ksp2redux.org) を確認

### 新しいMODの作成

ReduxのMODは、統合MODローダー、Redux MOD開発SDK、および現在のRedux
APIを使用します。ワークフローは、バニラKSP2のBepInExMODとは異なるため、新規プロジェクトのセットアップを始める前に、まずは最新のドキュメントを確認してください。

- **MOD開発ドキュメント：** [modding.ksp2redux.org](https://modding.ksp2redux.org)
- **APIリファレンス：** [api.ksp2redux.org](https://api.ksp2redux.org)
- **開発に関するサポート：** [Discord](https://discord.gg/ksp2redux)の **#🔴mod-dev**
  で質問してください

詳細については、[Modding SDK ブログポスト](/blog/modding-tools-unity-editor/)をご覧ください。

## プレイヤー

コンテンツを制作していなくても、貢献できる重要な方法はあります！

### テストとバグ報告

<GuideCards set={'testing'} />

### フィードバックの提供

- 新機能に関する体験を共有
- 利便性を向上するための提案をする
- Discordでの議論に参加
- 機能に関するコミュニティ投票に参加

### バグの報告方法

推奨される方法は、**ゲーム内のバグ報告ツール**：

1. **Ctrl+B** を押すか、**Escape → バグを報告する** を選択してください。
2. このツールは自動的に以下を添付します：
   - バグのスクリーンショット
   - ゲームログ
   - セーブファイル
   - システム情報

この情報は、バグをより速く再現・修正するのに役立ちます！

### 提案する

改善のためのアイデアはありますか？ぜひお聞かせください！

- [Discordサーバー](https://discord.gg/ksp2redux)に参加
- **#🟡redux-suggestions** フォーラムを使用
- 具体的に述べ、その提案がなぜゲームの改善につながるのかを説明してください。

## コンタクトとはじめに

The best way to get involved is through our Discord server:

**[Join the KSP2 Redux Discord →](https://discord.gg/ksp2redux)**

You do not need to be available all the time. Redux is a volunteer project, so
clear communication and genuine interest in the project matter more than
constant availability.

When you reach out, include a few references depending on what you want to help
with. Examples include GitHub repositories, mod pages, code samples, screenshots
or renders of 3D models, shader work, animations, design work, videos, writing
samples, or a portfolio. You do not need to provide references for translation,
but previous translation or writing experience is useful to mention.

We cannot promise that every person who reaches out will immediately have
something assigned, but if you have relevant experience and want to help finish
what KSP2 started, please contact us.

### Key Channels

- **#🟡redux-news:** News about KSP2 Redux
- **#🟡redux-dev-tracker:** Important messages by Redux devs
- **#🟡redux-resources:** Links to important Redux & modding resources
- **#🟡redux-chat:** General Redux discussion
- **#🔴mod-dev:** Mod development help
- **#🟡redux-suggestions:** Feature suggestions and ideas

### Key Contacts

- **@safarte** - Art Lead, Translation Coordinator
- **@.munix** - Developer Contact
