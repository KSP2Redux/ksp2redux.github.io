Reduxは、リソース管理の難易度レベルが異なる2つの進行モードがサポートされる予定です。「フロンティアモード」に先駆けて、「探索モード」が実装される計画となっています。

**探索モード**は、より気軽にゲームを進められるモードです。ミッション、サイエンス、発見、そして新たな機能のアンロックに重点が置かれています。リソースも引き続き重要ですが、その主な役割は、新たな要素をアンロックするための条件として機能することです。

**フロンティアモード**は、より奥深いリソース管理が求められるプレイ形式です。ここでは、パーツ、コロニー、燃料、建築資材といった要素を、生産・保管・輸送・消費すべき対象として扱います。

これらは、KSP1の「サイエンス」モードや「キャリア」モードの、おおまかな後継にあたるものだと考えてもよいです:

| モード    | KSP1との最も近い比較対象 | メインフォーカス                           |
| ------ | -------------- | ---------------------------------- |
| 探索     | サイエンス          | 探索し、実験を行い、ミッションを完了し、リソースやパーツをアンロック |
| フロンティア | キャリア           | コロニー、工場、備蓄、補給路からなる経済を構築            |

## 簡易な比較

| 質問                    | 探索モード                                         | フロンティアモード                                 |
| --------------------- | --------------------------------------------- | ----------------------------------------- |
| パーツを製作する際、資源は消費されますか？ | いいえ。必要なリソースがアンロックされれば、パーツをいくらでも製造できるようになります。  | はい。パーツを製造するには材料や燃料といったコストがかかります。          |
| 資源の量や生産速度は重要ですが？      | 基本的には違います。資源へのアクセスはアンロックとして扱われます。             | はい。採掘、処理、備蓄、そして流量が中心となります。                |
| コロニーは何のためのものか？        | コロニーネットワーク全体で資源へのアクセスをアンロックし、共有するため。          | 資材、燃料、コロニーパーツ、および機体を生産するため。               |
| 補給ルートは必要ですか？          | いいえ。目的は、物流管理をくり返し行うのを防ぐことです。                  | はい、計画された補給ルートは、コロニー同士をつなぐ上で重要な要素です。       |
| どういうプレイヤー向けですか？       | 複雑な経済管理を必要とせず、探検を支えるための目的としてのコロニーを求めているプレイヤー。 | コロニーの配置、生産チェーン、そして物流が重要な意味を持つことを求めるプレイヤー。 |

## 探索モード

探索モードでは、資源が進行および探索のシステムとして機能します。

資源を絶えず採掘して消費し続けるのではなく、コロニーにおいて特定の資源を利用できるように「アンロック」する仕組みとなっています。このアンロックには、コロニー内の特定の施設、ミッション、実験、特定の場所、あるいはその他の何らかの条件が必要となる場合があります。

条件が満たされると、その資源はそのコロニーにおいて利用可能なものとみなされます。機体やコロニーの構成要素がその資源を必要とする場合、備蓄量や生産率を把握することなく、その場所で製造することができます。

### 探査モードにおける軌道型コロニー

軌道型コロニーは、天体間における資源の結節点として機能するよう計画されています。

2つの天体それぞれに稼働中の軌道型コロニーが存在する場合、それらのネットワークを通じて、アンロックされた資源を共有することが可能です。例えば、ドゥナ（Duna）とカービン（Kerbin）の両方に軌道型コロニーがある場合、ドゥナ周辺でアンロックされた資源を、カービンの軌道ネットワークに接続されたコロニーで利用できるようになります。その逆も同様です。

その目的は、すべてのプレイヤーに貨物ルートの管理や保管容量の制限への対処を求めることなく、軌道型コロニーを有用なものにすることです。

## フロンティアモード

フロンティアモードでは、資源が生産および物流システムとして機能します。

このモードでは、機体やコロニーのパーツを建造・製造する際に資材が必要となります。パーツを建造・製造するには、その建造・製造する場所に必要な資材がそろっていなければなりません。これらの資材は、採掘施設で採取された未加工の資源を、工場で加工することで得られます。

生産量は、現地の資源密度、コロニーの状態、電力、熱、あるいはその他のバランス調整要素といったものに左右される可能性があります。具体的な項目は、まだ確定したものではありません。

KSCでは、基本的な製造・建築資材や一般的な燃料を無制限に利用できるようにする計画です。これにより、ゲーム序盤において物流上のボトルネックに直面することはありません。一方、より高度なパーツの入手やコロニーの拡大、特殊な資源の確保には、カービン外のコロニーが必要となる見込みです。

### フロンティアモードにおけるコロニー

フロンティアモードにおけるコロニーは、生産拠点です。

新たなコロニーを設立したり拡張したりする際には、カービンや他のコロニーから、資源、資材、あるいは建設用機材を輸送する必要があるかもしれません。コロニーが確立されれば、現地の資源を採掘して有用な資材に加工したり、燃料を生産したりできるようになり、最終的には、その場で機体やコロニー施設を建造することも可能になります。

ロードマップの後の段階では、繰り返される手動の貨物輸送を減らすための「補給ルート」が計画されています。あるコロニーから別のコロニーへの配送が成功した場合、それを定期的なルートとして登録して保存することで、時間をかけて継続的に資源を輸送できるようになります。

## 両モードに共通する点

どちらのモードも、コロニー、資源、ミッション、サイエンス、そして技術の発展といった要素を取り入れる予定です。モードの違いは、資源が存在するかどうかではありません。プレイヤーにどの程度の資源管理を求めるか、という点が異なります。

探索モードにおいて、資源は **「このパーツが必要とするものを発見し、アンロック済みなのか？」** という問いに対する答えとなります。

フロンティアモードにおいて、資源は **「あなたのコロニーネットワークは、このパーツのコスト分を生産・貯蔵し、供給することができるか？」**
という問いに対する答えとなります。

## 現在のステータス

Reduxは現在 **ステージ0：ファウンデーション**
にあります。パブリックベータ版の開発は、まだパフォーマンス、バグ修正、UIの整理、モッディングツール、熱管理、機体ISRUの基礎作業、および技術ツリーの要件に重点を置いています。

探索モードにおけるコロニーおよび資源に関するルールは、フロンティアモードの前に計画されています。コロニー、完全な資源ネットワーク、そして両モードのアップデートは、いずれもロードマップ上のより後の段階で予定されています。
