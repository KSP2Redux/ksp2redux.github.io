## 当前状态

<Aside type="caution" title="模组需要更新">
由于从BepInEx迁移到了集成式模组加载器，并且模组制作API也得到了改进，现有的模组都需要更新后才能与Redux配合使用。
</Aside>

## 纯资源类模组

部分纯资源类模组（尤其是部件模组）可能无需改动即可在Redux上运行，但我们目前不保证兼容性。

**什么是纯资源类模组？**
- 仅添加模型、纹理和配置的部件模组
- 替换纹理或模型的视觉类模组
- 不含代码或插件的模组

## 代码类模组

大多数基于代码的模组需要更新后才能与Redux配合使用：

### 有哪些变化？
1. **模组加载器：**从BepInEx迁移到集成式模组加载器
2. **模组制作API：**模组制作API的改进与变更
3. **核心系统：**部分游戏系统已被重写（例如TransformFrame）

### 对于模组使用者

请耐心等待模组开发者更新其模组以兼容Redux。可查看模组页面或联系开发者，了解Redux兼容性状态。

### 对于模组开发者

我们正在积极处理：
- **模组制作文档：**Redux模组制作的完整指南
- **迁移协助：**帮助模组作者更新其模组
- **无人维护的模组：**我们自行更新热门的无人维护模组

<Aside type="tip">
如果你是模组作者并且有意将模组迁移到Redux，欢迎在[KSP2 Redux
Discord](https://discord.gg/ksp2redux)的**#🟡redux-chat**频道中联系我们，或私信@safarte。
</Aside>

## Redux模组制作SDK

Redux带来了革命性的模组制作体验：

### Unity编辑器集成
- 在Unity编辑器中直接运行KSP2来测试模组
- 几秒完成迭代，而非几分钟
- 使用Unity完整的调试与开发工具
- 使用自定义检视面板和Unity包库

### 对模组作者的好处
1. **快速迭代：**可以立即测试改动
2. **更好的调试体验：**可随时使用Unity的完整调试工具
3. **更轻松的开发：**无需编译—测试—重启的循环
4. **更好的API：**更完善、更全面的模组制作接口

更多详情请参阅我们[关于Unity编辑器集成的博客文章](/blog/modding-tools-unity-editor/)。

## Checking Mod Compatibility

### Before Installing a Mod

1. Check if the mod page mentions Redux compatibility
2. Look for "Redux" or "v0.2.2.0+" in the supported versions
3. Check the mod's discussion page or Discord for Redux compatibility info
4. Test in a separate Redux install if possible

### After Installing a Mod

- Watch for errors in the logs
- Test functionality thoroughly
- Report issues to the mod developer (not the Redux team unless you're sure it's
  a Redux issue)
