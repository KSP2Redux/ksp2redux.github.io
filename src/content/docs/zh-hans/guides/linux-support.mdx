KSP2 Redux可以通过Proton在Linux上运行。本页重点介绍游戏本身的启动与故障排除。

<Aside type="tip" title="需要通过Steam启动">
如果你使用的是Linux版更新程序，并且希望能从更新程序启动游戏，请打开**设置**并启用**通过Steam启动**。
</Aside>

## 推荐配置

- 通过Steam添加或启动Redux。
- 为游戏强制启用Proton兼容性设置。
- 如果游戏在启动时不稳定，请先以窗口化启动选项启动。

据报告可用的Proton版本包括：

- `GE-Proton`
- `GE-Proton 10-27`
- `Proton Experimental`
- `Proton 10`

如果某个Proton版本出现画面或启动问题，请先尝试`GE-Proton`。

## 有帮助的启动项

一些Linux用户报告，强制窗口化启动能获得更好的稳定性。

建议尝试的启动参数：

```text
-popupwindow
```

其他据报告可用的选项：

```text
-window-mode exclusive -screen-fullscreen 0
```

备注：

- 据报告，`-popupwindow`能在某些系统上减少启动崩溃。
- 有些用户需要先让游戏以窗口化方式启动，即使之后能成功切换到全屏。
- 如果游戏一启动就崩溃，或打开后只有黑屏，请先试一个上面的选项，再做其他改动。

## Known Working Reports

The following Linux environments were reported to work by community members:

- Arch Linux with Hyprland using GE-Proton
- Nobara using GE-Proton
- Bazzite / Fedora Atomic using Proton
- Linux Mint 22.3 using GE-Proton 10-27
- Pop!_OS 24 using Proton 10

## 故障排除

### Startup Crashes

Try these steps in order:

1. Force `GE-Proton`, for example `GE-Proton 10-27`.
2. Add `-popupwindow` to launch options.
3. If that does not help, try `-window-mode exclusive -screen-fullscreen 0`.

### Videos or Intro Playback Issues

Some Linux users reported that default Proton builds had trouble with videos,
while `GE-Proton` worked correctly. If the game launches poorly or hangs early,
switch Proton versions before deeper troubleshooting.

## Reporting Linux Issues

When reporting a Linux-specific problem, include:

- your distro
- desktop environment or window manager
- kernel version
- GPU and driver version
- Proton version
- launch options used
