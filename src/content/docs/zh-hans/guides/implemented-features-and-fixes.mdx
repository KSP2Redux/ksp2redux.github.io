Redux仍处于Beta测试阶段。与Redux之前的原版KSP2相比，它增加了新的部件和任务、飞行与地图视图改进、EVA扩展内容、UI整理、图形更新、安装程序开发、模组工具，以及基础游戏中的大量修复。

本页面列出了Redux中已有的主要内容，按领域分组，以便比完整的发布说明更易于阅读。

如需查看每次更新的完整发布说明，请参阅[开发博客](/blog/)和[GitHub发布页](https://github.com/KSP2Redux/Redux/releases)。

本内容反映的是截至**v0.2.8.5**的当前公开状态。

## 概览

- 游戏的引擎已升级至Unity 6.4，并提供了改进的模组工具，包括Redux模组开发SDK和模组模板，以及集成的SpaceWarp、Patch
  Manager和适用于KSP2的UITK。
- Redux新增了部件、科技树改动、新任务、舱外活动降落伞、头盔灯、自定义旗帜、贴花以及一个统计窗口。
- 飞行和地图视图进行了许多实用修复与新增内容，包括更好的SAS操控、更高的时间加速倍率、KSP1风格的轨道相机行为、暂停时编辑机动节点、可见的地图旗帜以及航天器分类。
- VAB（航天器组装大楼）与建造流程在撤销、支撑杆、对称、分级、整流罩、对接口、部件操作以及部件放置性能方面进行了大量修复。
- UI方面的工作包括全新的颜色管理器、重构的轨道信息面板、更优的部件菜单搜索、更清晰的通知、更好的本地化与字体处理，以及各种其他UI改进。
- 图形、特效与性能方面的工作包括云层和太阳耀斑的调整、各天体专属的再入颜色、超采样、多线程渲染设置，以及减少许多模拟和UI系统中的内存分配压力。

## 新增与改进的功能

### 部件与科技树

- 新增了热控部件，包括TCS-400X和TCS-200F散热器。
- 新增了中小型轨道级与发射级引擎、燃料箱、转接器、分离器、切分器、助推器、隔热罩、锥形载人舱以及探测核心。
- 新增了特小固体火箭助推器、相机部件、程序化机身襟翼以及贴花部件。
- 扩展了科技树以纳入Redux部件。
- 为整流罩新增了可选的级间段支持。
- 新增了SDK工具，可帮助模组制作者生成部件图标、阻力立方体、再入网格、引擎尾焰和整流罩罩体。
- 新增了SDK辅助工具，用于部件着色器、音频设置、交互预设、梯子和气闸。

### 飞行与地图视图

- 已插下的旗帜现在会以旗帜颜色显示在地图视图中。
- 旗帜可从地图视图中删除，且当战役旗帜更改时，已插下的旗帜会保留其原有设计。
- 新增了飞行中的相机视野调整功能。
- 新增双击聚焦部件功能，以及重置飞行相机状态的快捷键。
- 新增了KSP1风格的天体/轨道相机行为。
- 新增了暂停时创建和编辑机动节点的功能。
- 新增了机动节点控制手柄的滚轮精确输入功能。
- 改进了地图视图中的机动节点弹窗和燃烧轨迹颜色。
- 新增了精密操控模式变更以及应用或重置配平时的通知。
- 新增了时间加速限制和加速至指定点时的更清晰反馈。
- 新增了在太空中使用Alt键启用物理时间加速的功能。
- 新增了1000,0000倍时间加速。
- 改进了时间加速限制，使安全轨道受到的约束更少。
- 改进了物理加速状态文本和颜色反馈。
- 新增了航天器分类和图标，使地图和追踪站中的身份识别更清晰。
- 新增了已展开部件的气动应力行为。
- 改进了SAS稳定性，包括若干边缘情况的错误修复，并改善了高动压下的行为。
- 新增了普通模式和精密模式下的平滑飞行操控。
- 改进了分离、解除对接和对接后的航天器命名。

### EVA（舱外活动）

- 新增了可切换的坎巴拉人头盔灯。
- 新增了在含氧天体上以及指令舱内摘头盔的功能。
- 新增了舱外活动降落伞，包括滑翔、机构颜色以及外部座椅支持。
- 允许舱外活动的坎巴拉人从指令舱和探测器中取出已存储的科学报告。
- 禁用了舱外活动出口阻挡检查，以减少常见情况下的出口受阻问题。

### 科学、教程与任务

- 新增了一项功能，可将科技树节点锁定在任务和科学实验之后。
- 新增了新的任务发布者和任务控制中心标志。
- 新增了第1、2、3级门户任务。
- 新增了“机械公敌”任务系列。
- 新增了原版任务集之外的其他任务。
- 在飞行报告窗口中新增了已存储的研究报告。
- 新增了更低的科学奖励难度下限选项。
- 改进了面向任务作者的任务目标揭示行为。
- 修复了若干任务解锁、目标检查、奖励和完成规则方面的问题。

### UI与体验优化

- 新增了游戏内错误报告工具，可通过Esc菜单或Ctrl+B打开。报告可以包含日志、版本信息、截图、存档及其他附件。
- 在主菜单中添加了Redux制作人员名单。
- 新增了模组菜单更新通知，当有新的Redux版本可用时显示。
- 在主菜单和Esc菜单中新增了统计窗口，用于追踪各种玩家统计数据和游戏里程碑。
- 新增了从模组文件夹加载自定义旗帜的功能。
- 在设置菜单中新增了战役旗帜更改功能。
- 新增了改进的组装大楼部件菜单搜索，并支持标签。
- 在工程师报告旁新增了警告图标。
- 新增了全新的颜色管理器，支持预设持久化、工具提示以及更佳的状态处理。
- 新增了增强轨道信息。
- 在部件操作管理器中新增了资源显示。
- 新增了散热器动作组按钮。
- 新增了高级部件操作，例如“从对称中移除”。
- 为对接口新增了“添加到分级”开关。
- 在组装大楼中新增了科学部件的部署预览。
- 在组装大楼的应用栏中新增了任务追踪器按钮。
- 在研发中心新增了鼠标滚轮滚动功能。
- 整理了Redux和SpaceWarp的UI样式，包括模组菜单、加载界面、旗帜站点、滚动条和窗口。
- 改进了在超宽屏、3:2及其他非16:9显示器上的UI行为。
- 改进了本地化覆盖范围和字体处理，尤其是针对中文、日文和韩文文本。
- 统一了原版UI与模组UI之间的字体。
- 新增了禁用光敏性警告的设置。

### 图形、特效与音频

- 为太阳耀斑新增了日出与日落的颜色变化。
- 为各个行星添加了不同的再入效果颜色。
- 新增了云层，并改进了原版云的形状。
- 新增了太阳耀斑图形开关。
- 为飞行和组装大楼新增了超采样，以牺牲部分性能为代价提升画质。
- 恢复了倒计时音效，并改进了从存档加载后的倒计时行为。

### 安装程序、工具与基础设施

- 新增了Redux启动器，用于安装、更新、降级、卸载和启动Redux。
- 新增了Discord游戏状态同步。
- 新增了通过Alt+F12调用的集成调试工具，支持多个系统。
- 禁用了已被关停并导致错误的原版在线服务。
- 改进了日志系统。
- 新增了DirectStorage支持。
- 为SDK新增了跳过启动画面的功能。

### 模组支持

- 集成了核心模组库与工具：SpaceWarp、Patch Manager、V-SwiFT、Shoemaker以及适用于KSP2的UITK。
- 将Unity版本从2022.3升级至Unity 6.4。
- 新增了Redux模板支持，以及面向Redux模组的模组开发SDK工作流。
- 新增了“莎士比亚计划”，这是一个实验性的KSP1部件模组转KSP2部件模组转换器。
- 新增了UITK辅助工具，用于事件绑定、命令、声音处理、本地化转换、应用外壳和对话框。
- 新增了共享UI组件，用于调整大小、拖动手柄、工具提示、自动文本尺寸调整以及常用模组窗口。
- 新增了一个API，用于在UITK和UGUI窗口之间进行鼠标点击排序。
- 改进了光标下UI检查，使原版代码能够识别模组UI。
- 改进了KerbalUI主题，并摆脱了对已弃用的UITK实验性控件的依赖。
- 围绕Lua脚本重写了Patch Manager，提供更完善的诊断信息、生成的存根、补丁排序控制以及配置值。
- 新增了Patch Manager辅助工具，用于选择、音频预设、PAM可见性、缓存、摘要和错误报告。
- 新增了面向Patch Manager Lua工作流的Visual Studio Code扩展。
- 为SpaceWarp控制台新增了REPL支持。
- 新增了通过Redux和SpaceWarp配置系统进行的共享配置注册。
- 改进了V-SwiFT的变体跟踪和附着节点集成。

- 修复了若干支撑杆问题，包括放置、对称以及交叉连接方面的问题。
- 修复了组装大楼的崩溃情况，以及一些由建造错误引发的发射爆炸问题。
- 修复了多个与预览残影、对接口交互、动作组、散热器及可展开部件相关的对称错误。
- 修复了分级创建、分级重排、中止动作、对接口、分离器以及“添加到分级”的边缘情况问题。
- 修复了复制部件时未复制资源的问题。
- 修复了程序化机翼在组装大楼中不会重新计算质量的问题。
- 修复了组装大楼相机重置以及飞机模式下的相机行为问题。
- 修复了首次加载时整流罩创建的问题。
- 修复了若干整流罩问题，包括穿模检查、卡顿、吸附对齐、直径选择、屏蔽、级间段行为以及透明材质。
- 修复了可展开部件在展开过程中被阻挡的问题。
- 修复了颜色管理器的预设处理、吸管工具行为、撤销行为、应用模式以及本地化按钮溢出的问题。
- 修复了对接口在连接头锥或其他组装大楼附件后卡住、无法对接的问题。
- 修复了原版航天器在关闭后仍显示在发射台上的问题。
- 修复了发射按钮在某些情况下失效的问题。
- 修复了发射后玩家可能卡在组装大楼、无法继续的问题，即使加载画面已经结束。
- 修复了组装大楼部件信息和尺寸类别可读性方面的问题。
- 修复了动作组管理器中热控标签页无法使用的问题。
- 改进了组装大楼在放置部件和加载航天器数据时的性能。
